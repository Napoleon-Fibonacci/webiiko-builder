# Folder skill

Setiap berkas `.md` di folder ini disisipkan otomatis ke pesan sistem
sebelum Build dimulai. `README.md` diabaikan.

Aturan penulisan:

- Satu berkas = satu topik. Contoh: `gaya-desain.md`, `penulisan.md`.
- Maksimal 5 berkas, total 15.000 token. Lebih dari itu, context habis
  sebelum kode ditulis.
- Tulis aturan yang bisa diperiksa. "Buat cantik" tidak berguna;
  "judul maksimal 2 baris di 390px" berguna.
- Jangan menaruh kunci API, email, atau data pribadi.
- Skill berlaku untuk **semua** Project. Jangan menulis aturan yang
  hanya cocok untuk satu situs.

Skill tidak bisa dipanggil Agent kapan saja. Isinya selalu ada di awal
percakapan dan tinggal di riwayat sampai Build selesai.
